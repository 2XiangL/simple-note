# 英文语言支持（系统语言自动切换）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 Simple Note 增加英文界面：启动时检测系统语言，中文系统显示简体中文，其余一律英文。

**Architecture:** 新增 Tk-free 纯逻辑模块 `lang.py`（`detect_system_language()`/`set_language()`/`get_language()`/`t(key)`，中文串即 key + `EN_TRANSLATIONS` 字典），`main.py` 启动时锁定语言，全部 UI 文案改经 `t()` 取用；`settings.json` 持久化格式与内部键（紧凑/标准/宽松）完全不变，仅显示层翻译。

**Tech Stack:** Python 3.14 标准库（`ctypes`/`locale`/`os`）、Tkinter、pytest（`uv run pytest`）。

**Spec:** `docs/superpowers/specs/2026-08-16-i18n-design.md`

## Global Constraints

- 语言判定：任何中文变体（LCID 主语言 ID == 0x04，含 zh-CN/TW/HK/SG/MO）→ `"zh"`；非中文 → `"en"`（英文兜底）
- `lang.py` 必须 Tk-free（`reminder.py`/`notify.py` 依赖它保持纯逻辑可无显示器单测）
- UI 文案一律 `from lang import t` 后裸调 `t("中文原文")`；en 译文只进 `EN_TRANSLATIONS`，**任何代码不得写 `lang.t(...)` 前缀形式**（完整性测试用正则 `\bt\("` 扫描）
- zh 模式 `t(key)` 原样返回 key；en 缺 key 回退 key（漏译退化为中文，绝不抛/绝不空）
- `settings.py` 与 `settings.json` 格式零改动；行距单选 `label=t(name)` 但 `value=name`（内部中文键）
- 用户录入的提醒 label 是内容数据，绝不翻译；stderr 开发者警告（tray/singleinstance/app）保持中文
- `image_resizer.py`/`util.py`/`snote.py`/`imefont.py`/`singleinstance.py`/`settings.py` 不改
- 现有测试全部保持通过（conftest autouse fixture 强制 zh 后，断言中文文案的用例一行不改）
- 提交遵循 Conventional Commits + scope（`feat(lang)`/`feat(app)`/`feat(reminder)`/`feat(main)`/`feat(ui)`/`feat(reminder-dialog)`/`docs(agents)`）

def _win_lcid():
    """Windows 用户界面语言 LCID；非 Windows 或 API 失败返回 None。"""
    if sys.platform != "win32":
        return None
    try:
        import ctypes
        return ctypes.windll.kernel32.GetUserDefaultUILanguage()
    except Exception:
        return None


def _locale_code():
    """当前 locale 代码（如 "zh_CN.UTF-8"）；失败回退 LANG 环境变量，再失败 None。"""
    try:
        code, _enc = locale.getlocale(locale.LC_CTYPE)
    except Exception:
        code = None
    if not code:
        code = os.environ.get("LANG")
    return code


def detect_system_language():
    """返回 "zh"（任何中文变体，含繁体）或 "en"。英文兜底。"""
    lcid = _win_lcid()
    if lcid is not None:
        return "zh" if (lcid & 0x3FF) == 0x04 else "en"
    code = _locale_code()
    if code:
        return "zh" if code.lower().replace("_", "-").startswith("zh") else "en"
    return "en"


def set_language(code):
    """显式覆盖语言；None 重置为自动检测（测试惰性检测用）；非法值归 "en"。"""
    global _lang
    if code in (None, "zh", "en"):
        _lang = code
    else:
        _lang = "en"


def get_language():
    """当前语言；未设置时惰性检测并缓存。"""
    global _lang
    if _lang is None:
        _lang = detect_system_language()
    return _lang


def t(key):
    """取当前语言的文案。zh 原样返回；en 查 EN_TRANSLATIONS，缺 key 回退 key。"""
    if get_language() == "en":
        return EN_TRANSLATIONS.get(key, key)
    return key
